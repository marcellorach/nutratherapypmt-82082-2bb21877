# Clinical Evidence Papers

Papers que demonstram efeito de nutracêuticos em doenças geriátricas caninas.

## Como adicionar

1. **NÃO** copie o PDF para esta pasta.
2. Vá em **Admin → Documentos Científicos** e faça upload pela UI.
3. O pipeline cuida: vetorização → extração de triplets → curadoria.
4. Esta pasta é apenas backup local opcional.

## Foco

- Espécie: cães (canine)
- Condições: metabólicas/degenerativas geriátricas (DCC, OA, DRC, hepatopatia, sarcopenia)
- Tipo preferido: RCTs, meta-análises, revisões sistemáticas
