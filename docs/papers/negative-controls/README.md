# Negative Controls

Papers que comprovam **ausência de efeito** ou **falha terapêutica**. Essenciais para o predicate `FAILS_TO_TREAT`.

## Alvos da Fase 1 (5 pares canônicos)

| # | Composto | Condição | Referência sugerida |
|---|---|---|---|
| 1 | Glucosamine + Chondroitin | Canine Osteoarthritis | Bhathal 2017; Aragon 2007 |
| 2 | Vitamin E (alfa-tocopherol) | Cognitive decline | Petersen 2005 (humano, extrapolado) |
| 3 | Beta-carotene | Lung cancer | ATBC 1994; CARET 1996 (humano) |
| 4 | SAMe (isolado) | Hepatopatia avançada | Vandeweerd 2013 review |
| 5 | CoQ10 | Progressão DRC | Singh 2003 (humano), gap canino |

## Processo

1. Upload pela tab **Documentos Científicos**.
2. Na curadoria, marcar `evidence_polarity = 'negative'`.
3. Predicate: `fails_to_treat` ou `no_effect_on`.
